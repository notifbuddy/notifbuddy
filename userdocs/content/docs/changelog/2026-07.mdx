## July 26

- **bugfix: New channels doesn't add relevant members automatically** — when a Slack channel is created for an issue, the creator, assignee, and profile `@`mentions are invited 
automatically (along with your Auto-add members), including on `@notifbuddy` create.

## July 25

- **breaking: Linear event envelope shape** — templates and conditions use typed paths (`linear.issue.*`, `linear.comment.*`) instead of `linear.data`. Comment events include an injected `linear.issue` so naming works on `@notifbuddy` creates. Update any saved templates that still reference `linear.data`. [Templates](/templates)

## July 20

- **feature: Self-hosting on Kubernetes** — a Helm chart, published to Artifact Hub. [Self-hosting guide](/self-host)

## July 19

- **feature: Attachments sync both ways** — Slack files land in the Linear comment; Linear images render inside the mirrored Slack message. Needs a one-time Slack reconnect.
- **feature: Channel rules cleanup** — Save moved into the config card header; removing a config asks for confirmation first.

## July 17

- **bugfix: Message sync between Linear and Slack** — comments stopped mirroring in both directions; webhook handling was repaired and messages now post with the author's own identity when their account is linked.

## July 5

- **launch: notifbuddy beta is live** — a Slack channel per Linear issue, comments and threads mirrored both ways. [Getting started guide](/getting-started)
