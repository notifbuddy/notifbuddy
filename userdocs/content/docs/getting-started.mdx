## Steps

1. **Connect Slack** — authorize the workspace so notifbuddy can post.
2. **Connect Linear** — install the app to sync issues and statuses.
3. **Configure channel rules** — pick when channels open (see [Templates](/templates)).

Prefer the terminal? The [CLI](/cli) covers the same steps with
`notifbuddy connect` and `notifbuddy settings`, and its bundled skill lets a
coding agent such as Claude Code run the whole onboarding for you.
